# Accelerator Server

Kivy-приложение: телефон превращается в сервер, который принимает подключения по TCP и
отвечает на обнаружение по UDP.

## Как работает

| Что | Порт | Назначение |
|---|---|---|
| TCP | 45000 | Принимает подключения клиентов, отвечает `OK` на каждое полученное сообщение |
| UDP | 45001 | Отвечает `ACCELERATOR_SERVER_HERE` на широковещательный запрос `DISCOVER_ACCELERATOR_SERVER` |

Большая кнопка по центру запускает и останавливает сервер. Строка сверху показывает
текущий статус и IP подключившегося клиента.

## Сборка APK

Сборка идёт в облаке через GitHub Actions, локально ничего ставить не нужно.

1. Открыть вкладку **Actions** в этом репозитории
2. Выбрать **Build APK** слева
3. Нажать **Run workflow** → **Run workflow**
4. Дождаться зелёной галочки (первый раз 30–60 минут: скачиваются Android SDK и NDK)
5. Внизу страницы запуска в разделе **Artifacts** скачать `acceleratorserver-apk`
6. Распаковать архив — внутри `.apk`, его можно ставить на телефон

## Локальная сборка (Linux/WSL)

```bash
bash build_wsl.sh
```

APK появится в папке `bin/`.

## Разрешения Android

В манифест добавляются `INTERNET`, `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE`,
`CHANGE_WIFI_MULTICAST_STATE`. Без `INTERNET` открыть серверный сокет на Android
невозможно — система выдаст `Permission denied`.

## Установка на телефон

Скачанный APK подписан отладочным ключом, поэтому при установке нужно разрешить
установку из неизвестных источников. Для публикации в Google Play нужен релизный
keystore.
